Project DJ Engine

역할
단독 개발
기간
2022년 6월—현재
지원 환경
Windows / Linux / macOS

리듬 게임, DJ 퍼포먼스, DAW형 음악 도구를 만드는 Godot 개발자를 위한 오픈소스 툴킷입니다.

만든 이유
리듬 게임 개발자는 오디오 재생, 저지연 입력, 노트 판정, 저작 도구, 음악 분석 기능을 직접 조합하고 동기화해야 합니다. PDJE는 이 기반을 하나의 재사용 가능한 Godot 시스템으로 제공합니다.
담당 업무
전체 아키텍처부터 재생·편집 런타임, DSP 통합, 장치 입력, 리듬 게임 판정, IPC, 데이터 저장, 패키징, 자동 배포까지 설계하고 구현했습니다.
만들 수 있는 것
동기화된 리듬 게임, 실시간 또는 사전 제작된 DJ 퍼포먼스, 게임 내 차트·믹스 편집기, 저지연 입력 시스템, 음악 검색과 파형 분석 도구를 개발할 수 있습니다.
  • 구조네이티브 C++ 코어와 Godot용 GDExtension 인터페이스를 분리
  • 런타임C++20, miniaudio, Faust, Cap’n Proto, SQLite
  • 배포자동화 워크플로 10개 · 래퍼 구성 6개 · 관리 라이브러리 21개

03.5

병렬 연산 / 신호 처리

OCCAstft

역할
GPGPU / DSP 개발
기간
2023—2024
프로파일링 환경
NVIDIA H100

GPU와 CPU 실행 환경, 비동기 프록시 전송을 하나의 처리 규약으로 연결하는 오픈소스 이기종 STFT 시스템입니다.

해결하려는 문제
대용량 신호를 처리하는 호출 코드가 특정 GPU API, CPU 백엔드, 전송 방식에 종속되지 않으면서도 여러 실행 환경을 사용할 수 있어야 합니다.
설계 결정
공통 요청 규약이 CUDA, OpenCL, OpenMP, 서버, Serial 실행 환경을 선택하고, OKL 커널이 Stockham FFT 파이프라인을 구현하도록 구성했습니다.
벤치마크
NVIDIA H100에서 윈도 크기 15종을 테스트했습니다. 저장소에 크기별 측정 결과와 CSV 생성 스크립트를 공개했습니다.
  • 실행 환경CUDA → OpenCL → OpenMP → 서버 → Serial 순서의 대체 실행
  • 처리 과정오버랩 → 윈도 적용·DC 제거 → Stockham FFT → 파워 또는 packed half-complex 출력
  • 프로파일링2의 거듭제곱 크기 15개, 2⁶—2²⁰ · NVIDIA H100 · Ubuntu · CUDA 12.3
