OCCAstft

Role
GPGPU / DSP developer
Period
2023—2024
Profile host
NVIDIA H100

An open-source heterogeneous STFT system for large signal batches. A common processing contract spans GPU and CPU runners while a standalone proxy selects an available runtime.

  • ExecutionCUDA, OpenCL, OpenMP, Serial; runtime fallback
  • PipelineOverlap → window/DC removal → Stockham FFT → power or packed half-complex output
  • TransportIXWebSocket, Cap’n Proto, Windows/POSIX shared memory
  • Evidence15 power-of-two sizes, 2⁶—2²⁰; OCCA/cuFFT/clFFT comparison artifacts
