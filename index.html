Project DJ Engine

역할
단독 개발
기간
2022년 6월—현재
지원 환경
Windows / Linux / macOS

리듬 게임, DJ 퍼포먼스, DAW형 음악 도구를 만드는 Godot 개발자를 위한 오픈소스 툴킷입니다.

만든 이유
리듬 게임 개발자는 오디오 재생, 저지연 입력, 노트 판정, 저작 도구, 음악 분석 기능을 직접 조합하고 동기화해야 합니다. PDJE는 이 기반을 하나의 재사용 가능한 Godot 시스템으로 제공합니다.
직접 구현한 범위
전체 아키텍처부터 재생·편집 런타임, DSP 통합, 장치 입력, 리듬 게임 판정, IPC, 데이터 저장, 패키징, 자동 배포까지 설계하고 구현했습니다.
만들 수 있는 것
동기화된 리듬 게임, 실시간 또는 사전 제작된 DJ 퍼포먼스, 게임 내 차트·믹스 편집기, 저지연 입력 시스템, 음악 검색과 파형 분석 도구를 개발할 수 있습니다.
  • 구조네이티브 C++ 코어와 Godot용 GDExtension 인터페이스를 분리
  • 런타임C++20, miniaudio, Faust, Cap’n Proto, SQLite
  • 배포자동화 워크플로 10개 · 래퍼 구성 6개 · 관리 라이브러리 21개

03.2

연구 시스템 / 햅틱 / XR

End-to-End MR Haptic Texture Workflow

역할
석사 연구원
기간
2025년 3월—현재
발표
AsiaHaptics 2026

하나의 혼합현실 세션 안에서 햅틱 텍스처를 취득하고, 모델링하고, 분석하고, 재현하는 독립형 Meta Quest 워크플로입니다.

해결하려는 문제
무선 센서와 헤드셋 런타임 사이에서 텍스처 취득, 온라인 모델 생성, 분석, 진동 촉각 재생이 하나의 일관된 흐름으로 동작해야 합니다.
구현
ESP32 시계 정렬, 네이티브 C/C++ 모델링, 공간 보간, Godot 통합, OpenXR 부동소수점 PCM을 하나의 연구 시스템으로 결합했습니다.
공개 근거 범위
AsiaHaptics 2026 시연을 목표로 개발 중인 프로토타입이며, 공식 공개 저장소와 출판 페이지는 아직 제공되지 않습니다.
  • 프로토타입$26.27 센서 부착물 · MPU6050 + QA6P FSR + ESP32
  • 데이터 취득1 kHz 가속도·힘 측정 · Wi-Fi 환경에서 PTP 방식에 착안한 시계 오프셋 정렬
  • 런타임Godot 4 · 네이티브 C/C++ GDExtension · OpenXR 부동소수점 PCM

처리 과정 / 하나의 혼합현실 세션

03.3

병렬 연산 / 신호 처리

OCCAstft

역할
GPGPU / DSP 개발
기간
2023—2024
프로파일링 환경
NVIDIA H100

GPU와 CPU 실행 환경, 비동기 프록시 전송을 하나의 처리 규약으로 연결하는 오픈소스 이기종 STFT 시스템입니다.

해결하려는 문제
대용량 신호를 처리하는 호출 코드가 특정 GPU API, CPU 백엔드, 전송 방식에 종속되지 않으면서도 여러 실행 환경을 사용할 수 있어야 합니다.
설계 결정
공통 요청 규약이 CUDA, OpenCL, OpenMP, 서버, Serial 실행 환경을 선택하고, OKL 커널이 Stockham FFT 파이프라인을 구현하도록 구성했습니다.
공개 근거 범위
H100에서 15개 윈도 크기를 측정한 원본 JSON, 통합 CSV 생성 과정, 크기별 프로파일링 결과를 저장소에 보존하고 있습니다. 검토된 결과표가 준비되기 전까지 비교 성능 향상 수치는 제시하지 않습니다.
  • 실행 환경CUDA → OpenCL → OpenMP → 서버 → Serial 순서의 대체 실행
  • 처리 과정오버랩 → 윈도 적용·DC 제거 → Stockham FFT → 파워 또는 packed half-complex 출력
  • 프로파일링2의 거듭제곱 크기 15개, 2⁶—2²⁰ · NVIDIA H100 · Ubuntu · CUDA 12.3
