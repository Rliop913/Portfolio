CAVE Escape Room
================

.. rubric:: Unity / Multi-Projection / LiDAR SDK Integration

Context
-------

A Unity escape-room game in a multi-projection CAVE space, where wall touches
are detected using LiDAR and drive the interactive content.

My Responsibility
-----------------

- Implemented CAVE interactions in Unity using the LiDAR SDK.
- Implemented the escape-room game logic.
- Implemented game objects and animations.

Interaction Boundary
--------------------

``LiDAR -> SDK processing -> Unity interaction / game logic -> objects and animation``
